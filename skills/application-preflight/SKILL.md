---
name: application-preflight
description: Prepare job-application answers and record outcomes locally in this repository without sending or submitting.
---

Read the specific card, eligibility evidence, final resume review and job-level
history. Use `src/applications.py prepare` with confirmed salary/currency,
availability, education category and sponsorship answers. Ask for missing facts;
estimate salary only when delegated, using current evidence.

Ready answers are not approval. Record explicit approval for the specific card
separately. The repo has no submitter. For separately authorized external work,
record submitted/duplicate_blocked only from the employer's observed result with
evidence. A click, disabled button or timeout is not submission confirmation.
Finish with the actual state and remaining required information.
